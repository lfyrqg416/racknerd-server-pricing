## 先想清楚用途，再谈配置

配置选错的成本比选贵的高得多。独立服务器是整台物理机独享，性能、硬盘 IO 和带宽都不受虚拟化层限制，但不同用途对配置的要求方向完全不一样：

- **游戏服务器（Palworld、幻兽帕鲁这类）**：吃 CPU 主频，核数反而次要。RackNerd 官方博客给 Palworld 推的方案是 E3-1240 V2（4 核 3.40GHz，睿频 3.80GHz）加 32GB 内存，月付 $70 或季付折合 $55/月，可选纽约、洛杉矶、达拉斯、芝加哥机房，官方说明是“游戏服务器需要高主频处理器，Palworld 对内存占用很大”。
- **视频转码**：看的是单核性能和 iGPU。官方博客推出过 E-2288G 机型（8 核 5.0GHz 睿频，PassMark 17,320），明确支持 QuickSync 硬件转码，部署在犹他和洛杉矶。
- **备份、媒体归档这类大容量需求**：盘位和流量才是重点，CPU 随便。后文表格里的 160TB 存储特供机就是干这个的。
- **自建 VPS / 多 IP 业务**：内存、IP 数量和流量都要大。注意 RackNerd 条款规定嵌套虚拟化需要书面批准，买 Virtualization Node 之前建议先开工单确认。

对国内访客友好的业务要单独说明：RackNerd 的机房分布在美国、欧洲，资料中没有中国优化线路的宣传。如果你的用户主要在国内，后文竞品对比里有更适合的选择。

1. **默认无退款。** 条款原文是付款后默认不退款（个案申请可能获批，预付款和账户余额一律不退）。付款前把配置和机房选对，别指望买错再退。

4. **默认不含备份，且默认非托管。** 官方要求客户自行保留网络外的备份；24/7 工单支持只覆盖硬件、电力、网络这些底层问题，软件环境、防火墙、安全加固都是你自己的事。
5. **交付不是即时的。** Hybrid 和 VPS 类产品付款后 30 分钟内交付；整机物理机需要装配时间，第三方跟踪口径为通常 48 小时内，急用的话预留一两天。

这些条款里最容易吃亏的是第 1 条和第 3 条——一个管你的钱，一个管你机器上跑什么。介意“买了不能退”的话，可以把第一周当作验证期：先跑通环境和线路测速，不合适赶在自动续费前取消。
